## Day 1 — Variables + Data Types + Strings

### Concepts | مفاهیم
- Variables and assigning values  
  متغیرها و مقداردهی

- Basic data types: `str`, `int`, `float`, `bool`  
  نوع‌های داده‌ی پایه: متن، عدد صحیح، عدد اعشاری، بولی

- Using `print()` for output and `input()` for user input  
  استفاده از `print()` برای نمایش خروجی و `input()` برای گرفتن ورودی

- Type conversion with `int()` and `float()`  
  تبدیل نوع داده با `int()` و `float()`

- String methods: `strip()`, `split()`, `join()`, `replace()`, `title()`, `upper()`, `lower()`  
  متدهای مهم رشته برای پاک‌سازی، جداسازی، اتصال، جایگزینی و تغییر حروف

- String indexing and slicing  
  دسترسی به کاراکترها و بخش‌هایی از رشته

- f-strings for formatted output  
  استفاده از f-string برای ساخت خروجی خوانا و حرفه‌ای

- Basic conditional logic with `if / elif / else`  
  منطق شرطی پایه با `if / elif / else`

- Math operators: `+`, `-`, `*`, `/`, `**`, `%`  
  عملگرهای ریاضی پایه

- Basic input validation  
  اعتبارسنجی اولیه ورودی‌ها

## Day 2 — Conditions + Loops

### Concepts | مفاهیم
- Comparison operators: `==`, `!=`, `>`, `<`, `>=`, `<=`  
  عملگرهای مقایسه‌ای

- Logical operators: `and`, `or`, `not`  
  عملگرهای منطقی

- `for` loops for known repetitions  
  حلقه `for` برای تکرارهای مشخص

- `while` loops for condition-based repetition  
  حلقه `while` برای تکرار بر اساس شرط

- Using `range()` in loops  
  استفاده از `range()` برای تولید بازه عددی

- `break` and `continue`  
  قطع کامل حلقه یا رد کردن یک دور از حلقه

- Nested loops  
  حلقه‌های تو در تو

- Validation logic for real user input  
  منطق اعتبارسنجی برای ورودی‌های واقعی کاربر

- Boolean flags like `is_prime`, `has_digit`, `is_valid`  
  استفاده از متغیرهای بولی برای کنترل وضعیت

- State changes in programs like ATM, guessing game, and Fibonacci  
  تغییر وضعیت متغیرها در برنامه‌های تعاملی و مرحله‌ای

### Challenges | چالش‌ها
- Sometimes I confused `input()` with `print()`.  
  بعضی وقت‌ها بین `input()` و `print()` اشتباه می‌کردم.

- It took time to understand how `range()` works and why the last number is not included.  
  زمان برد تا بفهمم `range()` چطور کار می‌کند و چرا عدد آخر را شامل نمی‌شود.

- I had to learn that a `while` loop can become infinite if the variable inside its condition does not change.  
  یاد گرفتم که اگر متغیر داخل شرط `while` تغییر نکند، حلقه می‌تواند بی‌نهایت شود.

- I had some confusion about string indexing, list indexing, and slicing.  
  در فهم تفاوت بین ایندکس‌گذاری رشته، ایندکس‌گذاری لیست و slicing کمی ابهام داشتم.

- I needed practice to understand the correct order of conditions in validation logic.  
  برای فهم ترتیب درست شرط‌ها در منطق اعتبارسنجی به تمرین نیاز داشتم.

- Building longer programs by combining multiple small logic blocks was challenging at first.  
  ساختن برنامه‌های بلندتر با ترکیب چند بخش منطقی کوچک در ابتدا برایم چالش‌برانگیز بود.
